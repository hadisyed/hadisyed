# Hadi Personal Website

A simple, professional static personal website designed for GitHub Pages.

## Files
- `index.html`
- `style.css`
- `script.js`

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload the three website files to the repository root.
3. Commit the files.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save. GitHub will provide your live website URL.

You can edit the text directly inside `index.html`.
